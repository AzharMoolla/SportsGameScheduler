# Basketball Blender study — 7 October 2026

Local review: http://127.0.0.1:5173/sports/basketball?art=studio
The existing theme switch selects broadcast/dark or program/light. This is an opt-in study; other sports and the default artwork are unchanged.

Editable sources: basketball-broadcast.blend and basketball-program.blend.
The original geometry, procedural textures, lights and three cameras are generated by scripts/blender-basketball-studio.py using Blender 5.2.2 LTS. No third-party models were imported. Ball rotation is keyed; physical net simulation is not baked. The light version is an illustrated shader study, not a finished watercolor treatment. Exported PNG/WebP images are raster; the editable 3D geometry can be re-rendered at new resolutions.

Regenerate the PNGs with the installed Blender executable in background mode, passing `--python scripts/blender-basketball-studio.py`. Then run `node scripts/export-studio-art.mjs` from the repository root for browser WebPs.

Validation: TypeScript and lint passed; 110 unit tests passed. Focused browser checks passed on desktop and mobile for both themes, asset delivery, visible schedule CTA and horizontal reflow. Screenshots are alongside this file. These checks establish local preview behavior, not production release readiness. No deployment was performed.
